# 10 — Riscos e pendências

1. **Crítico:** apresentar 13,5% de redução SUMO como resultado da maquete física.
2. **Crítico:** transições/firmware sem intertravamento, watchdog ou fase segura de pedestres comprovados.
3. **Alto:** contagem por quadro usada como veículos únicos, chegada por via ou fila estimada.
4. **Alto:** API, web e MySQL presentes no GitHub tratados como implantação testada ponta a ponta.
5. **Alto:** segredos de Aiven, JWT e chave de ingestão divulgados em frontend, mobile ou repositórios.
6. **Pendente:** cliente Python enviando leituras reais com via A/B válida, origem e UUID consistente.
7. **Pendente:** validação conectividade Aiven TLS, backup, migração SQL e dados de operação.
8. **Pendente:** aplicativo Mobile com código funcional.
9. **Pendente:** novos cenários virtuais, medição da maquete e revisão do artigo após novo PDF.
10. **Médio:** retenção de imagens/dados de pessoas, LGPD, custo de infraestrutura, métricas do dashboard limitadas por paginação.

Não promover status para validado sem teste real, versão de código, data, ambiente e evidência.
