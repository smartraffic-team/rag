# ADRs — Architecture Decision Records

Use um arquivo `NNNN-titulo-curto.md` por decisão, contendo **Contexto**, **Decisão**, **Alternativas**, **Consequências**, **Estado**, **Data** e **Responsável**. Registre mudanças de rumo, não apenas decisões finais. Não reescreva ADR aceito; substitua com novo ADR ligado ao anterior.
